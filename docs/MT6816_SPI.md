# MT6816 四线 SPI 角度读取

依据：用户提供的《MT6816》版本 2.1（2022.12），第 19–23 页，特别是图 17、图 19。

## 接线与模式

| STM32 引脚 | MT6816 引脚 | 信号 |
| --- | --- | --- |
| PB2 | 1 / CSN | 软件片选，低有效 |
| PA5 / SPI1_SCK | 7 / Z/W | 时钟 |
| PA6 / SPI1_MISO | 6 / B/V | 编码器输出 |
| PA7 / SPI1_MOSI | 5 / A/U | MCU 输出 |
| GND | 8 / GND | 共地 |

HVPP（2 脚）接 VDD，选择 SPI 功能；接地时为 ABZ/UVW。芯片的 SPI_Mode 必须为 0（四线模式）；例如 CT-STD 为四线，而 CT-STT 为三线型号。代码不会烧写 MTP 或切换出厂模式。按手册参考电路供电、去耦，并保证与 MCU 的 I/O 电平兼容。

SPI1 配置为主机、全双工、MSB first、模式 3（CPOL=1，CPHA=1）。SCK 空闲为高电平，下降沿切换数据，上升沿采样。硬件数据宽度为 8 bit，每次 DMA 传输 2 字节，组成手册规定的 16-clock 寄存器访问帧。DMA 保持 BYTE 对齐。

170 MHz SPI1 时钟 / 32 = 5.3125 MHz，周期约 188 ns，满足手册 TSCK >= 64 ns。片选下降后到首个时钟至少 100 ns，末个上升沿到片选上升至少半个 SCK 周期。代码用 64 次 NOP 加循环开销提供片选建立、保持和帧间间隔；这一设置针对当前 170 MHz、SPI /32 配置。

## 一次角度读取

命令字节为 `0x80 | 寄存器地址`。手册按传输先后标注的“比特 0”是先发送的 R/W 位，对应命令字节的最高位；不是 C 数值的 bit0。

1. CSN 拉低，发送 `83 00`，接收 `XX H`，CSN 拉高。`H` 是 0x03 的值。
2. CSN 再拉低，发送 `84 00`，接收 `XX L`，CSN 拉高。`L` 是 0x04 的值。

`XX` 是无效的首字节；第二个发送字节 `00` 用于提供读数据的时钟。一个 16-clock 帧内 CSN 必须持续为低，两帧之间必须为高。本实现遵循图 19 分帧读取，不假设寄存器自动连读，也没有 AS5047 的命令流水线。

```c
uint16_t word = ((uint16_t)H << 8) | L;
uint16_t raw = word >> 2;            // 14-bit，0..16383
float degrees = raw * 360.0f / 16384.0f;
float radians = raw * FOC_2PI / 16384.0f;
```

位分布：`H[7:0] = Angle[13:6]`，`L[7:2] = Angle[5:0]`，`L[1] = No_Mag_Warning`，`L[0] = PC`。

`word` 的全部 16 位应有偶数个 1。校验失败或弱磁报警时，本实现不更新角度，下一对寄存器继续尝试读取。例如 `H=0x40, L=0x01` 满足偶校验，解码为 4096，即 90°。

若需要超速报警，可独立发送 `85 00` 读取 0x05，返回字节的 bit3 为 Over_Speed；当前角度读取循环不读该寄存器。

## 工程调用链及接口

`FOC_Init()` 启动第一帧 → SPI1 RX DMA 完成 → `HAL_SPI_TxRxCpltCallback()` 保存高字节并启动第二帧 → 第二帧完成 → 校验并更新角度 → 启动下一对读取。

HAL 在完成回调前等待 SPI BSY 清除，回调再满足片选保持时间并拉高 CSN。编码器读取保留原工程的连续 DMA 链，与 ADC 电流环异步，读取频率取决于传输及中断开销，不代表固定的控制频率。

- `FOC_GetEncoderRawAngle()`：最后一次有效的单圈机械角度码。
- `FOC_GetAngle()`：软件累计多圈的机械角度，单位 rad。首次有效值以当前绝对角度为起点，不会将大于 180° 的首次读数误判为跨圈。
- `FOC_GetEncoderStatus()`：0 表示最近完成的一对角度数据有效；其余为位标志。

| 状态宏 | 含义 |
| --- | --- |
| FOC_ENCODER_NOT_READY | 尚无有效角度 |
| FOC_ENCODER_PARITY_ERROR | 最近一对数据偶校验错误 |
| FOC_ENCODER_NO_MAG | 最近一对数据报告弱磁 |
| FOC_ENCODER_SPI_ERROR | DMA 启动或 SPI 传输错误；片选释放、读取链停止 |

普通数据错误在下一次有效读取后清除。SPI 传输错误需要上层恢复外设并重新启动读取，当前没有自动恢复或自动停机策略；不要将保持的旧角度视为新采样。软件累计多圈要求相邻有效样本间转角小于半圈，长时间故障后不能保证圈数连续。状态接口也不具备通信超时检测。

## 验证与边界

在调试器观察 `FOC_GetEncoderRawAngle()` 对应的 `enc_raw`、`angle` 和 `enc_status`。逻辑分析仪按模式 3、MSB first 解码，应看到 `83 00` / `84 00` 交替发送，每 16 个时钟之间有 CSN 高电平。转动一圈，raw 应在 0..16383 范围变化并回绕。
